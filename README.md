# NuKeyAuto

Control your Nuki smart lock directly from Android Auto. Open, lock, or close your door from your car's dashboard.

## Features

- Android Auto integration: operate your smart lock from your car screen while driving
- Companion phone app with real-time lock status, battery level, and full control
- Configurable open delay and confirmation dialogs for safe operation
- Material 3 design with dynamic color, dark mode, and expressive shape animations
- Multi-language: English and Dutch
- Optional support-the-developer donations via Google Play

## Requirements

- Android 10 (API 29) or higher
- A Nuki smart lock with Nuki Web API access
- A Nuki Web API token and Smart Lock ID (configure in Settings)

## Build

Open the project in Android Studio and build. Signing credentials are read from `local.properties` (not in version control).
