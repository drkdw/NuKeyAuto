# Google Play listing assets

Upload these in Play Console > Grow users > Store presence > Main store listing. Made from the demo mode (simulated lock), light theme, English.

| File | Play Console field |
| --- | --- |
| `icon-512.png` | App icon (512 x 512, Play applies the mask) |
| `feature-graphic.png` | Feature graphic (1024 x 500) |
| `phone-*.png` | Phone screenshots (1080 x 2400) |
| `auto-*.png` | Android Auto screenshots (800 x 480) |
